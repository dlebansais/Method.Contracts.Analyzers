# MCA1022: Unverified method is using suffix

If a method doesn't have any of the contract attributes (`Access`, `RequireNotNull`, `Require` or `Ensure`) but ends with the `Verified` suffix (or the suffix defined in the project settings) it may incorrectly be confused with verified methods.
In that case, rename the method (if possible), or define a different suffix in the project settings.

## Sample code

```cs
private static void FooVerified() // MCA1022: Unverified method is using suffix.
{
}
```

Conformant code:

```cs
private static void Foo()
{
}
```
